$COMME Testnet

A communal supercomputer for the people, by the people.

Step 1: Install Rust

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

Step 2: Clone and Build

git clone https://github.com/commputer/commputer.git
cd commputer/src
cargo build --release -p commputer

Step 3: Create Your Wallet

./target/release/commputer wallet create

Write down your seed phrase! You cannot recover it later.

Step 4: Run Your Node

./target/release/commputer run --testnet --port 9000

Your node will automatically connect to the network, register as a validator, and start mining.

Step 5: Check Your Balance

./target/release/commputer wallet show --testnet
./target/release/commputer status --testnet

What Makes Commputer Different

  • 2 billion fixed supply — only goes down via burns
  • Anti-scale enforcement — warehouses get punished, desktops get rewarded
  • 5-channel Proof of Work: CPU, GPU, Storage, RAM, Bandwidth
  • Demand-weighted emission — the network decides what's valuable
  • No founder allocation — zero premine, zero dev tax

Commputer is open source and community-driven.

Scale hurts. Patience rewards.
